# Eval Samples

## Prompt
Create one short-answer cybersecurity question for beginners.

## Output
Question: What is the primary purpose of using strong, unique passwords in cybersecurity?

Answer: The primary purpose of using strong, unique passwords in cybersecurity is to protect individual accounts and sensitive data from unauthorized access by making it difficult for attackers to breach accounts through brute force, guessing, or credential stuffing. Strong passwords should be complex, containing a mix of uppercase and lowercase letters, numbers, and special characters, and should be unique for each account to prevent a single compromised password from affecting multiple accounts.

## Prompt
Create one MCQ about network segmentation.

## Output
1. Which of the following is NOT a primary benefit of network segmentation?
A) Improved security by limiting an attacker's ability to move laterally
B) Simplified network management and troubleshooting
C) Increased network performance due to reduced broadcast traffic
D) Enhanced compliance with data protection regulations
E) Reduced hardware costs due to consolidation

Answer: E) Reduced hardware costs due to consolidation (Network segmentation typically requires additional hardware, such as switches and routers, to create separate network segments.)
